# 托盘「打开默认应用设置」快捷跳转

> 日期：2026-08-03  
> 状态：已确认

## 背景

在现行 Windows（含 UCPD）下，第三方无法可靠静默改默认浏览器；管理员提权本身也不能越过 UCPD。产品已确认：**不做 UCPD 绕过 / 不以管理员重启实现直切**。用户需要托盘上一键进入系统设置完成确认。

## 决策

| 项 | 选择 |
| --- | --- |
| 快捷跳转目标 | `ms-settings:defaultapps`（默认应用总页） |
| 入口位置 | 托盘右键菜单，浏览器列表与「打开主窗口」之间 |
| 文案 | `打开默认应用设置…` |
| 实现 | 复用 `SettingsLauncher.OpenDefaultApps()` |
| 管理员提权直切 | **不做** |
| 浏览器菜单项行为 | **不变**（现有级联：可选社区工具 → COM → 关联 UI / 深链 → 总页） |

## 交互

托盘右键菜单顺序：

1. 各已检测浏览器（现有）
2. 分隔线
3. **打开默认应用设置…**（新增）
4. 打开主窗口
5. 退出

点击新增项：打开系统默认应用页；主窗口若已加载，可将状态栏设为提示「请在系统设置中选择目标浏览器」（可选，不阻塞）。

打开失败：沿用 `SettingsLauncher` 异常路径；必要时 `MessageBox`（与主窗口「设为默认」失败处理一致即可）。

## 非目标

- 以管理员重启本程序实现静默切换
- 禁用 UCPD / 改写 UserChoice 哈希
- 单独再做一个「深链到当前默认浏览器」的托盘项（浏览器项已覆盖深链回退）

## 验收

1. 托盘右键可见「打开默认应用设置…」
2. 点击后打开系统默认应用设置（Win10/11）
3. 不出现 UAC 提权框（本功能无需管理员）
4. 现有浏览器切换行为与主题菜单不受影响
5. 单元测试：若抽取命令/方法，覆盖「调用 OpenDefaultApps」；纯 UI 接线可手工验收
