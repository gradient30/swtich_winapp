# 浏览器切换器（Browser Switcher）设计文档

> 日期：2026-07-31  
> 状态：已确认

## 背景与目标

Windows 下切换默认浏览器需经过「设置 → 应用 → 默认应用 → Web 浏览器」多层路径，操作成本高。本工具以系统托盘常驻，一键打开系统默认应用设置页，并提示用户选择目标浏览器，缩短操作路径。

**成功标准：** 从托盘或主窗口选择浏览器后，即可打开系统默认应用页并看到明确提示；无需改注册表或管理员权限。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 形态 | 托盘常驻 + 可扩展简易主窗口 |
| 技术栈 | .NET 8 + WPF |
| 目标浏览器 | Brave、Google Chrome、Internet Explorer、Microsoft Edge |
| 检测 | 自动扫描；失败或覆盖时允许手动指定 `.exe` |
| 设为默认策略 | 始终打开系统「默认应用」页（`ms-settings:defaultapps`），不静默改关联 |

## 架构

**技术选型**
- .NET 8 + WPF
- Hardcodet.NotifyIcon.Wpf（系统托盘）
- 配置：`%AppData%\BrowserSwitcher\config.json`
- 单实例运行

**模块划分**

```
BrowserSwitcher/
├── App                  # 启动、托盘、单实例
├── UI/
│   ├── MainWindow       # 简易主窗口（浏览器列表 + 操作）
│   └── SettingsView     # 预留：手动路径、开机启动等
├── Services/
│   ├── BrowserDetector  # 扫描已安装浏览器
│   ├── SettingsLauncher # 打开 ms-settings:defaultapps
│   └── ConfigStore      # 读写配置（含手动路径）
└── Models/
    └── BrowserInfo      # 名称、可执行路径、图标、来源(自动/手动)
```

## 界面与交互

### 托盘
- 悬停提示：`浏览器切换器`
- 左键：显示/隐藏主窗口
- 右键菜单：浏览器快捷列表、「打开主窗口」、「退出」

### 主窗口
- 浏览器列表：图标 + 名称 + 状态（已安装 / 手动指定 / 未找到）
- 操作：「设为默认」「指定路径」
- 底部：`刷新列表`、`设置`
- 关闭窗口 = 隐藏到托盘（仅托盘「退出」才结束进程）

### 设置页（首版最小可用）
- 手动路径增删改
- 开机启动（可实现或占位）
- 关于 / 版本号

## 检测逻辑与数据流

### 自动检测顺序（每种浏览器）
1. 注册表常见安装键（App Paths、卸载/安装路径键等）
2. 常见默认安装目录（Program Files、LocalAppData 等）
3. 仍找不到 → 标记「未找到」，保留列表项并允许指定路径

### 手动路径
- 写入 `config.json`，同浏览器以手动路径优先
- 启动与刷新时校验路径是否存在；失效可提示并重新指定

### 设为默认流程
1. 用户选择浏览器
2. `SettingsLauncher` 启动 `ms-settings:defaultapps`
3. 应用内提示：请选择对应浏览器名称
4. 不修改注册表、不请求管理员、不静默改默认关联

### 数据流

```
启动 → ConfigStore 读配置
     → BrowserDetector 扫描 + 合并手动路径
     → 生成 BrowserInfo 列表
     → 主窗口 & 托盘菜单共用同一列表

点击「设为默认」→ SettingsLauncher 打开系统页 + 提示
点击「指定路径」→ 选 exe → ConfigStore 保存 → 刷新列表
```

### 错误处理
- 单项检测失败不影响其他项
- 打开设置页失败：弹窗说明
- 配置损坏：回退默认配置并提示

## 测试与验收

1. 启动后仅一个托盘图标；关主窗口不退出
2. 自动列出已安装的目标浏览器
3. 未找到项可手动指定 `.exe`，重启后仍保留
4. 选择后打开系统默认应用页，并出现「请选择 XXX」提示
5. 单实例：再次启动激活已有实例
6. 配置持久化

**测试手段：** 手工覆盖有/无安装、路径有效/无效；`BrowserDetector` / `ConfigStore` 用 xUnit 做单元测试。

## 非目标（首版不做）
- 静默/注册表方式强制改默认浏览器
- 管理员提权
- 热键（可后续扩展）
- 非目标列表外的浏览器自动发现（可后续扩展）
