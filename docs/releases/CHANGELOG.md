# 更新日志

面向用户的版本历史。发版流程见 [VERSIONING.md](VERSIONING.md)。程序内「?」帮助仅展示**当前版本**（`src/BrowserSwitcher/Resources/ReleaseNotes.md`）。

## 1.4.1

- 修复多次切换后默认浏览器被系统回滚：Hash 现基于 ProgId 写入后的时间戳计算
- 切换成功前增加短延迟二次校验，减少误报成功

## 1.4.0

- 新增 **ForceDirectSwitch**（默认开启）：内置 UserChoice + Hash 直写（http/https）
- 可选外部工具：SetUserFTA.exe、SetDefaultBrowser.exe（放入 Tools 目录）
- 设置页：UCPD 状态检测与禁用引导、直切开关
- 直切失败时弹窗提示，不再自动打开设置页

## 1.3.2

- 托盘右键菜单新增「打开默认应用设置…」

## 1.3.1

- 修复启动崩溃：主题菜单 TwoWay 绑定只读属性导致托盘不出现

## 1.3.0

- 切换级联：社区直切工具 → 系统关联页 / 设置深链
- 设置改为居中紧凑面板；取消不保存开机启动草稿
- 托盘菜单对比度与深浅主题体验巩固

## 1.2.0

- 修复菜单与列表文字对比度
- 深色 / 浅色主题，可在「视图」菜单切换并记住选择

## 1.1.0

- 界面焕新，设置入口移至顶部菜单
- 托盘支持一键切换默认浏览器，失败时打开系统设置
- 新开关图标，托盘提示显示当前默认浏览器

## 1.0.0

- 首个可用版本：检测 Brave / Chrome / IE / Edge，手动路径与开机启动
- 托盘常驻、单实例运行
