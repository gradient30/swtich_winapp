### Q-2: Hash algorithm test is non-deterministic-only (severity: low)

**Evidence:** `UserChoiceHashTests` validates Base64 shape but not a known-answer hash vector.

**Impact:** A subtle algorithm error could evade unit tests while still producing syntactically valid hash strings.

**Recommendation (proposal):** Add one known-answer test vector (fixed SID/timestamp/ProgId/extension).
